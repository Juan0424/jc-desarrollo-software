01 / IDENTIDAD

Tecnología construida
para resolver problemas.

JC Desarrollo de Software es una marca enfocada en crear herramientas digitales funcionales, aplicaciones y sistemas que ayudan a organizar y simplificar el trabajo.

JC

Mi enfoque es desarrollar software que tenga una utilidad clara. No se trata solamente de escribir código, sino de entender cómo funciona una operación y convertir sus necesidades en herramientas digitales.

Trabajo en proyectos que integran aplicaciones web, Android, bases de datos y servicios en la nube, buscando que las distintas partes funcionen de manera conectada.

Uno de mis proyectos principales es JC INVENTARIO, una solución de control de inventario y operaciones con aplicación web y móvil.

03 / PROYECTOS

Trabajo desarrollado.

Cada proyecto refleja una necesidad concreta y una solución construida para facilitar operaciones.

PROYECTO PRINCIPAL

JC INVENTARIO

Sistema de control de inventario y operaciones, desarrollado con una aplicación web administrativa y una aplicación Android para técnicos.

  • Administración de productos y proveedores.
  • Gestión de técnicos y usuarios.
  • Registro de entregas de productos.
  • Firma de recibido en las entregas.
  • Control de productos disponibles y utilizados.
  • Movimientos e historial de operaciones.
