Política de privacidad

Información sobre el tratamiento de datos durante la visita a JC Desarrollo de Software.

← VOLVER AL SITIO PRINCIPAL

1. Responsable del sitio

Este sitio web presenta los proyectos y servicios de JC Desarrollo de Software. Para consultas sobre privacidad puedes utilizar el medio de contacto publicado en la página principal.

2. Información proporcionada por los visitantes

El formulario de contacto de esta versión del sitio prepara un mensaje mediante la aplicación de correo del visitante. El usuario decide si desea enviarlo. El sitio no dispone de un sistema propio para guardar esos mensajes en una base de datos.

Si el visitante envía un correo, su contenido será tratado por los proveedores de correo involucrados y por el destinatario del mensaje.

3. Datos técnicos y alojamiento

El sitio puede estar alojado en una plataforma de infraestructura web que procese información técnica necesaria para entregar las páginas, mantener la seguridad y detectar problemas de funcionamiento. El tratamiento de esos datos también está sujeto a las condiciones y políticas del proveedor de alojamiento.

4. Cookies y herramientas de seguimiento

Esta versión del sitio no incorpora intencionalmente herramientas propias de publicidad, perfiles de seguimiento ni analítica de visitantes. Esta situación deberá revisarse si posteriormente se agregan servicios externos o nuevas funciones.

5. Enlaces externos

El sitio contiene enlaces a servicios de terceros, como GitHub y JC INVENTARIO. Al visitar esos servicios, el usuario queda sujeto a sus respectivas políticas y condiciones de privacidad.

6. Seguridad

No envíes contraseñas, códigos de acceso, documentos de identidad, datos bancarios ni información confidencial mediante el formulario de contacto de este sitio.

7. Cambios a esta política

Esta política podrá actualizarse cuando cambien las funciones del sitio, los servicios utilizados o las prácticas de tratamiento de información. La versión vigente estará disponible en esta misma dirección.
