INFORMACIÓN DEL SITIO

Política de privacidad

Este aviso explica cómo se trata la información cuando visitas el sitio web de JC Desarrollo de Software.

← VOLVER AL SITIO

1. Alcance

Esta política se refiere únicamente a este sitio web de presentación profesional. No sustituye la política de privacidad de JC INVENTARIO ni la de ninguna otra aplicación o servicio desarrollado por separado.

2. Información que introduce el visitante

Este sitio no cuenta con una base de datos ni almacena formularios de contacto. Cuando el visitante completa el formulario de contacto, el navegador prepara un mensaje mediante la aplicación de correo configurada en su dispositivo. El visitante decide si desea enviarlo. El tratamiento posterior del correo depende del proveedor de correo utilizado.

3. Cookies y analítica

La versión entregada de este sitio no incorpora herramientas propias de analítica, publicidad ni perfiles de seguimiento. Los servicios externos enlazados pueden aplicar sus propias tecnologías y políticas cuando el visitante accede a ellos.

4. Enlaces a terceros

El sitio puede enlazar a plataformas externas, como GitHub o la aplicación JC INVENTARIO. Esos sitios tienen sus propios términos y políticas de privacidad. Se recomienda revisarlos antes de proporcionar información personal.

5. Seguridad

El sitio está diseñado como una página informativa estática. No solicites ni envíes por este medio contraseñas, datos bancarios, documentos de identidad ni otra información confidencial.

6. Contacto y actualizaciones

Para consultas sobre este aviso, utiliza el medio de contacto que se publique en la página principal. Esta política debe revisarse y actualizarse cuando se incorporen formularios conectados a un servidor, analítica, cookies u otras funciones que cambien el tratamiento de datos.
